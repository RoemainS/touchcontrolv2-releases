# TouchControlv2 releases

Releasebron voor de automatische updates van TouchControlv2.

- **`latest.json`** — informatie over de nieuwste versie (versienummer, download-URL, SHA-256).
- **Installers** — beschikbaar als Release-asset onder [Releases](../../releases).

De app controleert periodiek `latest.json`, controleert de download op SHA-256
en installeert een nieuwe versie na bevestiging door de gebruiker.
